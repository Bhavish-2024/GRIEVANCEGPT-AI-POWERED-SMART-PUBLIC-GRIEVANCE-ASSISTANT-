GrievanceGPT System Architecture

Dual AI + Classical Machine Learning pipeline for intelligent civic intake.

Classical Machine Learning

Trained on CivicDex using hybrid character (2-5 ngrams) and word TF-IDF vectorization with balanced Logistic Regression. Classifies Intent, Category, Department, and Urgency in under 5ms.

Local Generative AI (Ollama)

Connects directly to local Qwen3:8b (or Qwen3:4b fallback) via Ollama. Powers conversational follow-up questions, structured JSON extraction, and grounded RAG synthesis.

Civic Prototype Scope: This system is an intelligent intake and preparation assistant designed to help citizens formulate complete, categorized complaints. It prepares structured grievances for administrative dispatch.
